# 📊 Study Time and Test Score Analysis

A beginner-friendly Data Science capstone project built with **Python, Pandas, SciPy, Matplotlib, Seaborn, and Scikit-Learn** to analyze how daily study duration relates to final test scores and build a predictive regression model.

---

## 🎯 Project Overview
The **Study Time and Test Score Analysis** project investigates whether students who spend more hours studying each day achieve higher scores in assessments. Using a 10,000-record student dataset, it compares test scores across study-time levels, measures statistical correlation, and evaluates a multivariable regression model.

The project demonstrates a complete Data Science workflow:

**Data → Inspection → Cleaning → Statistical Analysis → Visualization → Regression Modelling → Insights**
